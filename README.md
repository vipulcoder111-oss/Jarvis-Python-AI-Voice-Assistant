# 🤖 Jarvis AI Voice Assistant

> A Python-based voice assistant that listens to your voice commands, processes them, and responds using text-to-speech.

---

## ✨ Features

* 🎙️ **Voice Recognition** — Understands commands through your microphone.
* 🔊 **Text-to-Speech** — Responds using a computer-generated voice.
* 🕐 **Date & Time** — Provides the current date and time.
* 💬 **Voice Interaction** — Communicate with Jarvis using natural voice commands.
* ⚡ **Fast Response** — Processes commands and responds quickly.
* 🖥️ **Desktop-Based** — Runs directly on your computer.
* 🛠️ **Customizable** — Easy to add new commands and features.
* 🐍 **Python Powered** — Built completely using Python.

---

## 🛠️ Technologies Used

| Technology            | Purpose                   |
| --------------------- | ------------------------- |
| 🐍 Python             | Main programming language |
| 🎙️ SpeechRecognition | Converts voice into text  |
| 🔊 Pyttsx3            | Converts text into speech |
| 🕐 Datetime           | Handles date and time     |
| 🖥️ SAPI5             | Windows speech engine     |

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/Jarvis-AI-Voice-Assistant.git
```

### 2️⃣ Open the Project Folder

```bash
cd Jarvis-AI-Voice-Assistant
```

### 3️⃣ Install Required Libraries

```bash
pip install SpeechRecognition
pip install pyttsx3
pip install PyAudio
```

Or, if you have a `requirements.txt` file:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

Run the following command:

```bash
python jarvis.py
```

Make sure your **microphone is connected and working** before starting the assistant.

---

## 🎤 How It Works

```text
🎙️ User Voice
      ↓
🧠 Speech Recognition
      ↓
⚙️ Command Processing
      ↓
🔊 Jarvis Response
      ↓
💻 Text-to-Speech
```

Jarvis listens to the user's voice through the microphone, converts the speech into text, processes the command, and responds using voice.
